# Seed

A memory manager serves an online sequence of requests on a linear address space of cells 0, 1, 2, ...: allocate(s) asks for s contiguous free cells and the manager must choose where to put the block at once; free(b) releases a block allocated earlier. An adversary chooses the requests, seeing every placement, but may never have more than M cells live at once, and every block has size at most n. A manager that may never move a block can be forced to touch far more than M cells; a manager that may move everything at any time needs only M. Suppose the manager may move blocks, but moving a block of size s costs s, and its total moving cost may never exceed c times the total size it has allocated so far. For each c: what is the smallest heap size H(M, n, c) (highest cell ever used, plus one) that some manager can guarantee against every adversary? How does it fall from the no-moving value to M as c grows?
