Notation: H = h-1.  k_x(t) = number of the first t list entries equal to x.  F_x = number of firings
made at x so far.  eta_x = chips on x.  Always  eta_x = k_x - 2F_x + F_{x-1} + F_{x+1}.     (*)

THEOREM 1 (COMPLETE).  C(h) <= 5h-5 for every h >= 1.  Hence G(h) <= 5h-5.
Proof.  Constant list of zeros, length m.  Suppose Firer has a line in which every vertex holds
<= H chips after step (1) of round m.  At that moment there are m chips and at most m-1 firings
have been made.  Q = sum_x x^2 eta_x is unchanged by an add at 0 and raised by exactly 2 by a
firing ((x-1)^2+(x+1)^2-2x^2 = 2), so Q <= 2(m-1).
For every integer x:  x^2 >= 9 - w_x, with w_0=9, w_{+-1}=8, w_{+-2}=5, w_x=0 otherwise.  So
   Q >= 9m - (9 eta_0 + 8 eta_1 + 8 eta_{-1} + 5 eta_2 + 5 eta_{-2}) >= 9m - 35H.
Thus 9m - 35H <= 2m - 2, i.e. m <= 5H - 2/7, i.e. m <= 5H-1.  So the list of 5H = 5h-5 zeros wins. QED
(The problem's bound C(h) <= sqrt(24)(h-1)+O(1) is NOT valid.  Its estimate
"Q >= about n^3/(12(h-1)^2)" is a continuum estimate, but the game lives on about 5 vertices: the
lattice minimum of Q for n = 5H chips is 10H, below n^3/(12H^2) = 10.42H.  The bound is in fact
false for large h, because Theorem 2 gives C(h) >= G(h) >= 5h - O(sqrt h) and 5 > sqrt(24).)

THEOREM 2 (COMPLETE).  Let m >= 1 with  m/5 + 2 sqrt(m) + 13.2 <= h-1.  Then EVERY list of length m
loses.  Hence G(h) > m for all such m; in particular G(h) >= 5h - 10 sqrt(5h) - 72  (h large).
Firer's strategy.  Define the target  T_x = (3 k_x + k_{x-1} + k_{x+1}) / 5   (k after the current
add) and the lag  l_x = T_x - F_x.  In step (2): if some vertex x is ready and has l_x >= 1, fire
such an x with l_x largest; otherwise pass.
Facts.
 (a) l_x >= 0 always (T is nondecreasing in time; a firing needs l_x >= 1 and lowers l_x by 1).
 (b) Put eta*_x = k_x - 2T_x + T_{x-1} + T_{x+1}; direct expansion gives
       eta*_x = (k_{x-2}+k_{x-1}+k_x+k_{x+1}+k_{x+2})/5,  so 0 <= eta*_x <= t/5  (t = adds so far).
     By (*):  eta_x = eta*_x + 2 l_x - l_{x-1} - l_{x+1}.                                   (**)
 (c) l_x <= T_x <= 3(k_{x-1}+k_x+k_{x+1})/5 <= 3 eta*_x.
 (d) Let M = max_x l_x after an add, attained at x.  Then 2l_x - l_{x-1} - l_{x+1} >= 0, so by
     (**),(c): eta_x >= eta*_x >= M/3.  If M >= 6, x is ready and l_x >= 1, so the vertex fired
     in this round has lag exactly M.
 (e) Theta = sum_x g(l_x), g(u) = max(u-6,0)^2, satisfies Theta <= t after round t.
     Induction: an add raises lags by d = 3/5,1/5,1/5 on three vertices (total 1); g convex with
     g'(u) = 2 max(u-6,0), so the add raises Theta by at most sum d_i * 2 max(M-6,0) = 2 max(M-6,0),
     M = the max lag after the add.  If M < 6 then Theta = 0 after the add and firing cannot raise
     it.  If M >= 6, by (d) a vertex of lag M is fired, lowering Theta by g(M)-g(M-1), which is
     2(M-6)-1 if M >= 7 and (M-6)^2 if 6 <= M < 7; in both cases the round's net change is <= 1.
 (f) So after round t every l_x <= 6 + sqrt(t), and after the add of round t every
     l_x <= 6 + sqrt(t-1) + 3/5.  By (**),(a),(b): at every step of round t
       eta_x <= eta*_x + 2 l_x <= t/5 + 13.2 + 2 sqrt(t) <= h-1  for t <= m.  QED
(The strategy never needs to know the future of the list.  strategy_sim.py checks the invariants
(a) and (e) numerically; the lag never exceeded 2.2 there, so its checks of (d) and of the growth
of Theta were never exercised (Theta stayed 0).  Observed height <= t/5 + 3: the sqrt term is
probably an artefact of the proof, not of the strategy.)
