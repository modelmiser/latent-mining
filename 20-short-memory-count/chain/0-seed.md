# Seed

A deterministic machine with s states reads a stream of n bits one at a time and must then output an estimate of how many of them were 1. It can count exactly only if s > n. With fewer states it has to forget: what is the smallest worst-case error it can guarantee for each s and n, with error measured as an absolute difference or as a ratio; what do the best machines look like; how much does it help to know n in advance, to be allowed a second pass, or to read the stream in an order of the machine's choosing?
