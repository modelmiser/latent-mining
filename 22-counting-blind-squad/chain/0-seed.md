# Seed

n identical finite automata stand in a line. At each tick every automaton sees its own state and the states of its two neighbours (the end ones know they are at an end) and changes state by one common rule. At time 0 all are asleep except the leftmost, the general. The firing squad problem asks for a rule under which all n enter a special firing state at exactly the same tick, for every n, with a number of states that does not depend on n. This is possible, 2n - 2 ticks are necessary and sufficient, and six states are enough for the fastest solutions as far as is known, while four are not. Now weaken the automata: a cell sees only one bit about each neighbour, or sees only its left neighbour, or one cell of the line is deaf for a single tick at a moment chosen by an adversary. For each such weakening: is synchronisation still possible for every n, how many ticks does it take, and how many states are needed?
