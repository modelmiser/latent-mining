## Findings

1. **MODERATE, confidence high. README:92-93 (and :48).** "A coincidence worth testing" is already refuted by the same enumeration the referee ran (n up to 10). My enumerator gives five-state single-length minima n=9: 10 (256 rules synchronise n=9; 20 fire at 10), n=10: 13 (92 rules). Floor(3(n-1)/2) is 12 at n=9. Witness, order Q0 Q1 Q2 G0 G1 G2 U1.. : `0 3 1 0 1 3 4 0 3 2 3 0` fires n=9 at time 10 (checked with my second simulator; first three ticks by hand). One program of mine found it; it reproduces every other s=5 figure. Replace with: "The fastest five-state times for n = 2..8 equal floor(3(n-1)/2), but the pattern breaks at n = 9 (time 10, not 12; n = 10 gives 13)", after a second instance confirms.
2. **MODERATE, confidence high. README:99-101.** "could not fail (no rule there reaches the relevant case)" is wrong for four states: 511 pairs are tested there and 4,966 four-state rules fire some n before 2n-2, so a violation was possible; only the equal-time branch is never reached (`reports/referee.md:41`; my count agrees). Replace: "Solver A's test of its Lemma 2 is empty at three states (no rule synchronises two lengths) and at four states never meets the equal-time case (511 pairs, all in the 2n - 1 case); only the five-state test exercises both."
3. **MODERATE, confidence medium-high. README:82.** "It found no paper with cells that see only a count" contradicts `prior-art.md:11` (Rollier et al. 2025: count-based outer-totalistic binary automata on a task it calls FSSP; for two states that is own state plus a neighbour count). Replace: "It found no paper with this model. One paper (Rollier et al., 2025) uses count-based cells on a different task it calls firing squad (random start, global alternation)."
4. **LOW, confidence high. README:87-90.** "part of the result here follows" names no result the README states; L(3) = 2 does not follow from Yunès (`prior-art.md:16`: "n = 4 and L(3) = 2: NOT FOUND"). Replace: "With three states only single lengths 2 and 3 can be synchronised (solver B, enumeration); the n >= 5 part of that follows from ...; L(3) = 2 does not."
5. **LOW, confidence high. README:12-16.** "These are computed values: for five states every one ... was tried" leaves s = 6, 7 unqualified in the headline paragraph. Add: "For six and seven states the values come from backtracking searches, not full enumeration; an error there could only make them too small."
6. **LOW, confidence high. README:46.** "proved by hand by both solvers" for "length 3 or more", citing solver A: A's Lemma 1 proves n = 3 only (`solver-a/proofs.txt:6`); the n >= 3 statement is B's P1 (`solver-b/proofs.txt:1`). Cite `solver-b/proofs.txt` P1, P2 as well.
7. **LOW, confidence high. README:68-69.** "agree on the full table of how far each rule gets": what agrees is the histogram (counts per prefix), plus rule-by-rule agreement on the 1,244. Replace "full table of" with "count of rules reaching each length".
