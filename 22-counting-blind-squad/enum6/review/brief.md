The claim is a computation: `enum6/enum.c` goes through every six-state rule and finds that the largest N such that one rule synchronises every length 2..N is 8, attained by exactly 336 rules. Look for a bug that would make this wrong.

Verdict for each question: CONFIRMED / REFUTED / UNSUPPORTED, with file:line evidence.

- Q1. Read `enum6/enum.c` against the definition. Does `simulate` implement the model exactly: what a cell sees (own state and the number of EXISTING neighbours in a different state; end cells have one neighbour), synchronous update, the initial configuration (cell 1 is G, the rest Q), success = all cells F at the same tick with no F earlier, the fixed entry (Q, k = 0) -> Q? Is a partial fire treated as failure? Is the state encoding (3 bits per cell) safe for six states and the lengths reached?
- Q2. "Never fires": the program decides it only on an exact repeat of a configuration (Brent's cycle detection). Is the implementation of Brent's algorithm correct (it must detect every eventually periodic run and never report a repeat that did not happen)? Could a run be cut off for any other reason and counted as a failure (a step cap, the length cap NMAX)?
- Q3. Coverage: is the odometer over the 14 free entries complete (every one of 6^14 rules visited exactly once across the 216 chunks; check the chunking by the top three digits and `enum6/aggregate.py`, `enum6/aggregate_s6.txt`)? Is the per-rule N computed as "largest N with EVERY length 2..N synchronised" (stopping at the first failing length)? Is anything skipped?
- Q4. The definition of L(s) asks for one rule synchronising every length from 2 to N. Does "no rule has N >= 9" in the histogram establish L(6) = 8 exactly, given that 336 rules have N = 8? Any off-by-one between the histogram index and N?
- Q5. Validation: the same program at five states reproduces 1,244 rules equal as a set to `solver-b/all_L5_rules_s5.txt` (`enum6/compare_out.txt`), and four and three states. Is that a meaningful test of the six-state run (same code path, only S changed)? What kind of bug would it NOT catch?
