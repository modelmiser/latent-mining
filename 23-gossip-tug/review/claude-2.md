# Claude seat 2: experiment 23 (gossip-tug)

Paths are relative to `23-gossip-tug/`. Independent check: my own plain minimax (scratchpad, no symmetry, no pruning) gives A(2..5) = 1, 3, 6, 9, and 5, 8 for n = 4, 5 in the "no naming full agents" variant.

## Verdicts

- **Q1 CONFIRMED.** Replayed `solver-b/proofs.txt:27-39` against `chain/3-question.txt:1,3`. After {1,2}, naming 1 gives legal partners 3 and 4 only ({1,2} dead). After {1,3}, naming 2 gives legal partners 3 and 4 only ({2,1} dead). Reply 3: secret 4 has one knower, so 3 more calls are needed (Lemma 1), 6 in all. Reply 4: K2=K4=124. Naming 2 forces {2,3} (2-1 and 2-4 dead). K3=1234, and 3 is still active because 3∉K4. 3-1 and 3-2 are dead, so {3,4} is forced. K1=123, so a sixth call is needed. The symmetry steps (relabel the first call, swap 3 and 4) are sound because the Delayer's moves are stated relative to those labels. Naming a full agent is allowed: the rules require only that the named agent be "active" (3-question.txt:1,3).
- **Q2 CONFIRMED.** `solver-a/proofs.txt:9-23`. A partner p_i can't be called again because after {1,p_i} each knows the other's secret for ever. The phase lasts n−1 calls, because 1 is active exactly while K_1 ≠ [n]. At the end, K_{p_i} = P_i. Exactly two agents are full, since |P_{n−2}| = n−1. Unions of chain members stay in the chain. In a call between one full and one non-full agent, the non-full one becomes full (+1). In a call between two non-full agents, nobody does. Two full agents can't call. So at least n−2 more calls are needed. This holds for any phase-2 Delayer play. For n = 2 it gives 1 and for n = 3 it gives 3, both correct.
- **Q3 CONFIRMED.** Lemma 1 holds for every play, so it bounds the value. So does Lemma 2: every non-full agent must call. Lemma 3 gives a real Hastener strategy against every Delayer choice (I checked that the hypothesis is preserved). In `solver-b/ab2.cpp:58-69` the cut-offs point the right way: lower bounds return YES and upper bounds return NO. A false lower-bound lemma would push values up, and a false upper-bound lemma would push them down. The A(10) "NO at 28" result rests on Lemma 3 and the live-pair bound.
- **Q4 CONFIRMED for the checker. REFUTED for file availability.** `solver-a/check.py:53-74`: the D side recurses over every legal reply, rejects an inactive named agent and rejects missing positions. The H side requires a legal listed reply for every active agent. The canonical form (lines 20-39) is the minimum over colour-preserving orders after invariant refinement. That makes it a true canonical form, and quotienting is sound because the value is invariant under relabelling. But the files don't match the README (finding 1).
- **Q5 CONFIRMED with a scope defect.** "The game" (README:41-48) matches the formal text. The 2n−4 sentence is missing n ≥ 4 (finding 3).
- **Q6 CONFIRMED.** README:74-103 adds nothing to the proofs. "At most one new knower" is Lemma 1. "At most one fully informed agent per call" is stated inside the chain argument, where it holds; it is false for a general position.
- **Q7 REFUTED in part.** These match their sources: 5, 8, 10, 14, 16 and "8 against 7" (referee.md:128); the differences 2, 3, 3, 3, 4, 3, 4, 4 (solver-b.md:130); A053096 and "seven terms" (prior-art.md:181); the attributions for P1, Theorem A and the variant; and the lemma check up to n ≤ 8 (referee.md:95).
