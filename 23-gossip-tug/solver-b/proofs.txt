PROOFS (solver-b).  Notation: K_x = set of secrets agent x holds; "x knows y" means y in K_x.
A pair {x,y} is DEAD if x knows y and y knows x (then it can never be called again, since sets only grow),
otherwise LIVE.  "full" = knows all n secrets.  value(P) = number of further calls from position P under optimal play.

----------------------------------------------------------------------------------------------------
LEMMA 1 (COMPLETE).  For every secret s, value(P) >= n - #{agents knowing s}.  (True for every play, not only optimal.)
Proof.  A call {a,b} changes who knows s only if exactly one of a,b knows s, and then exactly one new agent
learns it.  So each call raises the number of knowers of s by at most 1; at the end it must be n.  QED

LEMMA 2 (COMPLETE).  value(P) >= ceil(u/2), u = number of non-full agents.
Proof.  Every non-full agent must take part in at least one more call; a call has two participants.  QED

LEMMA 3 (COMPLETE).  If P has at least one full agent and every non-full agent x fails to know the secret of
at least one full agent, then value(P) <= u (u = number of non-full agents).
Proof.  Hastener's rule: if the named agent a is non-full, answer with a full f whose secret a does not know
({a,f} is legal because f not in K_a); a becomes full.  If the named agent a is full, any legal partner b
must fail to know a (a knows b), so b is non-full and becomes full.  Either way the number of full agents rises
by >= 1 per call, and the hypothesis is preserved (a non-full agent not in the call keeps its set and its
missing full agent stays full).  So at most u calls are made.  QED
(Lemmas 1-3 are the only static cut-offs in ab2.cpp; value <= number of live pairs is the fourth, trivial one.)

THEOREM A (COMPLETE, by hand; also machine-checked: cert_n4_ge6.txt + check_cert.py, table4.txt + check_table).
A(4) = 6.  Hence the headline "A(n) = 2n-3 for all n >= 4" is FALSE, and it already fails at n = 4 (2n-3 = 5).
Proof.  Upper bound: no pair is called twice, so at most C(4,2) = 6 calls.
Lower bound (Delayer strategy).  Round 1: any agent; by symmetry the call is {1,2}.
Round 2: Delayer names 1.  Legal partners are 3,4 ({1,2} is dead); by symmetry the call is {1,3}.
  Now K_1 = K_3 = 123, K_2 = 12, K_4 = 4.  Two calls made.
Round 3: Delayer names 2.  Legal partners: 3 and 4 ({1,2} dead).
 Case (i) Hastener answers 3: K_1=K_2=K_3=123, K_4=4.  Secret 4 is known by one agent, so by Lemma 1
   at least 3 more calls: total >= 3 + 3 = 6.
 Case (ii) Hastener answers 4: K_2 = K_4 = 124, K_1 = K_3 = 123.  Three calls made.
   Round 4: Delayer names 2.  {2,1} and {2,4} are dead; 2 does not know 3, so the call is forced: {2,3}.
     Now K_2 = K_3 = 1234, K_1 = 123, K_4 = 124.
   Round 5: Delayer names 3 (it is active: 4 does not know 3).  {3,1} is dead (1 knows 3, 3 knows 1),
     {3,2} is dead, so the call is forced: {3,4}.  Now K_4 = 1234, and K_1 = 123 is still not full.
   Round 6: at least one more call is needed (agent 1 is not full; indeed {1,4} is legal).  Total >= 6.
QED
(The point of round 5: naming a FULL agent whose only legal partner is one of two "complementary" non-full
agents stops Hastener from finishing both of them with a single call {1,4}.)
