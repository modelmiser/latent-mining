## 1. KNOWN

Unrestricted shortest addition chains: l(n) >= ceil(log2 n); the binary method gives l(n) <= floor(log2 n) + (number of ones) - 1; Brauer's window method gives l(n) = log2 n (1 + o(1)); Erdos showed almost all n need about log2 n + log2 n / log log n. No closed formula; exact values come from search.

The seed is under-specified and partly degenerate. It never says what registers other than the one holding x contain at the start. With r = 1 only x^(2^k) is reachable. With r = 2 every n is reachable, since left-to-right binary needs only x and an accumulator, so "is n computable" is trivial for r >= 2 and only the step count is interesting. It also asks four questions at once (r, n, free squaring, division). Bounded-register chains relate to Euclidean/continued-fraction chains and Lucas chains; whether exact register-limited values are tabulated: unsure.

## 2. SUCCESSOR QUESTION

A two-address machine has exactly two registers, A and B, each holding a positive integer (the exponent of a power of x). Initially A = 1 and B = 1. The only instruction is "dst := dst * src", where dst and src are each one of A, B and may be the same register. In exponents, from state (a, b) one step leads to exactly one of four states:

- (2a, b)   [A := A*A]
- (a, 2b)   [B := B*B]
- (a+b, b)  [A := A*B]
- (a, a+b)  [B := B*A]

So a result always overwrites one of its own operands; there is no way to copy a register, and no other instruction exists. Each step costs 1.

For a positive integer n, let f(n) be the least number of steps after which at least one of the two registers holds n (f(1) = 0). f(n) is finite for every n: keep B = 1 and run the binary method in A, which gives f(n) <= floor(log2 n) + (number of ones in the binary expansion of n) - 1.

For k >= 1 define the worst k-bit cost

W(k) = max { f(n) : 2^(k-1) <= n < 2^k }.

Question: determine W(k) for every k >= 1. Concretely: (i) give the exact values W(1), ..., W(12), and for each such k the smallest n attaining the maximum; (ii) give and prove a formula for W(k) valid for all k, or, if no exact formula is provable, determine the limit of W(k)/k as k goes to infinity (prove it exists and give its value). In particular decide whether that limit is 1 (as it is for unrestricted addition chains), 2 (the binary method is essentially optimal in the worst case), or strictly between.

## 3. WHY IT IS PROBABLY UNCHARTED

The classical worst-case results (Brauer, Erdos) depend on keeping a table of small powers, which two overwrite-only registers forbid; the Euclidean-chain literature uses only the two additive moves, not the doublings. The mixture of four moves is the semigroup generated by four specific 2x2 matrices acting on (1,1), and shortest-word questions there are rarely closed-form. Doubts: register-bounded or "in-place" addition chains may have been studied under a pebbling or straight-line-program-space name I cannot recall, and the limit may follow from a short counting argument I have not found. The exact formula in (ii) may not exist.

## 4. HOW TO CHECK AN ANSWER

Register values never decrease, so a state with a value above N can never later hold any n <= N. Breadth-first search from (1,1) over pairs in [1,N]^2 with the four moves, N = 4095 (about 1.7 * 10^7 states), yields f(n) for all n <= N exactly; take maxima over each bit-length to get W(1..12) and compare. A claimed formula must match these values; a claimed limit needs an explicit strategy (upper bound) and a counting or potential-function lower bound, both checkable against the table.
