# Seed

To compute x^n by multiplications one may build an addition chain: start from x, and at each step multiply two powers already computed. The length of the shortest chain for n is known only for small n and has no simple formula; it lies between log2 n and about log2 n plus the number of ones in the binary expansion. A real machine has few registers. Suppose only r values can be held at once: each step multiplies two held values and the result must overwrite one of the registers (possibly one of its own operands), and the original x is held only as long as it sits in a register. For each r and n: what is the least number of multiplications, for which n does a small r cost extra steps, and how does the answer change if squaring a register in place is free or if division is allowed?
