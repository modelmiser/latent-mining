# Claude seat 2: R(4q+1) >= 3q - 1 (experiment 18 follow-up)

Method: I traced PROOF.md by hand against `chain/3-question.txt`. I wrote my own scheme and checker from PROOF.md's text alone, without importing quad.py or checker.py: tuple configurations, every legal sequence, a monotonicity check, and Q checked after every operation, including Q(0^n). I ran them for q = 1..4. I also recomputed the sequence counts and the comparison table independently.

Own run (scratchpad `seat2-q18x/mine.py`):

These counts match organiser_rerun.txt and run_quad.log wherever they overlap. The number of legal sequences of length <= 18 is 296,855,529 by my own recursion, and <= 17 / 15 / 14 give 99,095,529 / 11,080,169 / 3,715,049, all as logged. The checker can fail: every 3q+1 run fails.

## Verdicts

- **Q1 CONFIRMED.** PROOF.md:3 adopts the definition (3-question.txt:1-5). E only sets cells (PROOF.md:56; quad.py `kill` and `|=` only). Q and E read only `c`. Q(0^n) = EMPTY, so both readings hold (PROOF.md:9). POP on an empty stack is never applied: checker.py:142-144 skips it; in the scheme it is a "stay" that no legal sequence reaches.
- **Q2 CONFIRMED.** The mode-A invariant is P3 (PROOF.md:62-65). At the freeze, the clean leaves the quads before j* all DD, so N = () before the conversion. Waste kills plus the conversion remove exactly the entries of S in quads < j**, which are its bottom-most entries. R = O(quads >= j**) + (b) is a suffix of S + b (PROOF.md:111-116). The LL count (PROOF.md:96-100) is right: s = 2q + d, no LL means d >= q, so the freeze would be operation >= 3q + 1 > t.
- **Q3 CONFIRMED.** I re-derived s = 2#LL + 3#mixed + 4#DDnw + 3#DDw = 4q - |R| - w. A waste kill only hits non-LL quads and kills all their live pairs, so a mixed quad's dead pair was killed by a POP or a conversion, each charged 1, giving charge 3. A wasted quad was mixed (one charged kill), giving 3. DD not wasted gives 4. Left-zone quads are never LL, so LL quads are in the right zone. The freeze-converted quad is in the left zone thereafter, so it is never wasted, and w <= q - 1 (PROOF.md:91-94). Equality needs "no stay operation"; see LOW-1.
- **Q4 CONFIRMED.** A PUSH with j* = q+1 needs s >= 4q - #mixed - #DD = 3q (PROOF.md:119-120), which I checked. A POP with N non-empty: the last left-zone mixed quad becomes DD and j* is fixed. A POP with N empty: |O| >= 3 with quad j* contributing exactly 2, so the rightmost live pair is in some j' > j*; quad j* stays LL and the zones are unchanged (PROOF.md:125-131). Q is a function of the configuration: the flag selects the mode, and j*, N and O are computed from the cells. For q = 2, t = 5 I found no bad sequence by hand: the dangerous POP into quad j* needs |O| <= 2 with r >= 1, which (I2) forbids. The exhaustive run (209 sequences, plus 617 at t = 6) confirms this.
- **Q5 CONFIRMED.** R is monotone in n: a scheme can ignore an extra cell that stays 0. That gives 3·floor((n-1)/4) - 1 for n >= 5, and floor((n-1)/4) >= (n-4)/4 gives (3n-16)/4. I recomputed the comparison against max(floor(n/2)+2, 7). The new bound is strictly better at 17, 21, 22, 23 and every n >= 25, and ties at 13, 18, 19, 24, exactly as the page says.
- **Q6 CONFIRMED.** checker.py:131-165 explores every legal sequence, merging identical (config, stack) pairs, which is sound because play is deterministic. It checks containment and monotonicity (150-153) and Q after every operation (154-157). quad.py:61-100 matches PROOF.md. The one cosmetic difference is that a mode-B POP kills both pairs of the quad (96), which is the same as killing the live one. My independent implementation reproduces every logged number for q <= 4.
- **Q7 mostly CONFIRMED; two stale items and one under-supported item.** See the findings below.

**LOW-1: the induction in the proof is left implicit** (PROOF.md:70, 89, 107-109). "s = sum of charges" fails if a "stay" operation occurs (PROOF.md:54). The stays are excluded only by (I2) and the budget argument, and those are themselves derived from (1). The argument is sound by induction on s, but the text does not say so. Confidence: high that the proof is correct. Replacement after line 70: "No operation within the budget is a stay (shown below by induction on s, using (1) for the configurations already reached), so s = sum over quads of charge(quad)."

**LOW-2: the Short answer contradicts itself** (18-write-once-stack/README.md:9-10). Replacement: "In general the best lower bound proved here is the largest of ⌊n/2⌋ + 2 (n ≥ 6), 7 (n ≥ 8) and, from a follow-up of 21 November, 3·⌊(n − 1)/4⌋ − 1, about three quarters of n, which is the largest at n = 17, 21 to 23 and every n ≥ 25."
