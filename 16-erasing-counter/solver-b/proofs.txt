THEOREM 1 (COMPLETE).  D(r) >= a_r for all r >= 1.  Hence log2 D(r) >= 2^(r-1): not polynomially bounded in r.
Construction. W_1 = (1 [1] []).  W_r = (1  W'  W'') where W'' is a copy of W_{r-1} on positions 2^(r-1)+1 .. 2^r-1 and W' is a
copy of W_{r-1} on positions 2 .. 2^(r-1) in which the unique empty leaf is replaced by the leaf [1] (write the root).
(mkwit.py prints them; witness_r1..r5.txt.)
Inductive claim C(r): W_r is a valid depth-r tree on 2^r-1 positions, has exactly one empty leaf E, uses each position at exactly
one node, and the orbit of the all-zero state is a cycle of length exactly a_r on which E is used exactly once.
r=1: 0 -> 1 -> 0, leaf [] used once.  Step r-1 -> r.  Validity: depths grow by one; the new leaf [1] lies under the root, so 1 is on
its path; W' and W'' use disjoint positions, so W_r has one empty leaf (that of W'').  Write a state as (x, u, v): x the root bit, u the
bits of W', v the bits of W''.  Let g be the map of W_{r-1}.  If x=0 the step is (0,u,v) -> (e,g(u),v), with e=1 exactly when u uses the
replaced leaf (an empty leaf of g, so the u-part still becomes g(u); x was read as 0 and is rewritten only by that leaf).  If x=1 the step
is (1,u,v) -> (0,u,g(v)) (x is read hence erased, no leaf of W'' writes it).  Start at (0,0,0).  By C(r-1) the u-orbit of 0 under g
has period exactly a:=a_{r-1} and uses the replaced leaf exactly once per period.  So the run is: a x=0-steps per round, one of them
followed immediately by a single x=1-step; after k full rounds the state is (0,0,g^k(0)), reached after k(a+1) steps.  A return to
(0,0,0) needs: u=0 with x=0, which happens only when the number of x=0-steps is a multiple of a and the pending x=1 step (if any) has
been done, i.e. only at the round boundaries (inside a round the u-part is g^i(0) != 0 for 0<i<a, or i=a.. then the round is over); and
v=0, i.e. a | k by C(r-1).  First return: k=a, after a(a+1)=a_r steps.  E (in W'') is used once per a x=1-steps, i.e. once.  QED.
Lower bound on growth: a_r >= a_{r-1}^2 and a_1=2 give a_r >= 2^(2^(r-1)).
