# Claude seat 2 — experiment 16 upper bounds

Paths are relative to `16-erasing-counter/`. Everything below was traced by hand from `chain/3-question.txt:3-11`. I also ran one throwaway program of my own (outside the repository): 8,000 random trees on 3 to 6 indices, depth up to 6 with heavy index reuse, full functional graph of each. Result: at most 1 empty step on any cycle of length ≥ 2, 0 failures of RD over 2,331 trees with disjoint root subtrees, and no cycle longer than L(T).

## Verdicts

- **Q1 CONFIRMED** (`upper/PROOFS.md:16-22`). A step that reads c ones changes the weight by −c, or by 1−c if it writes. It reads no 1 only on the all-zero path. When Z(s) ≥ 1, the bits z_1..z_(i−1) are already 0, S_i can contain only z_j with j > i, and those read 0. So erasing z_i and making at most one write gives Z(f(s)) ≤ Z(s).
- **Q2 CONFIRMED** (`:32-46`). In Case A the weight is constant, so every step must have c = 1 and must write. Case B: if λ0 were empty, the state with Z = 0 would be a fixed point. λ0's set R lies on λ0's own path, and that path is Z, so λ0 cannot write a data index. Every state has Z ≤ 1 by (F2) applied once round the cycle. Home states are determined by their data bits because the Z bits are 0 and the other bits are constant. After (α) the only 1 left on Z is the one written: z_1..z_i were read and erased, and an unread z_j with j > i was already 0. So each excursion is: the λ0 step, then (α) steps, then exactly one (β) or (γ) step. Only the (γ) steps are empty.
- **Q3 CONFIRMED** (`:48-59`). F is finite: on any path K grows at most |data| times, and between two growths the modes are pairwise distinct. Indices on each F path are distinct, because K is exactly the set of indices kept on the path. Now take a leaf of S_i that writes data index u. If u's node in S_i was removed, it was removed because u ∈ K. If u was read in an earlier mode, it was kept there. Either way u lies on the F path. F is binary and idx(F) ⊆ idx(T) \ Z, which has fewer than m elements. The induction is on m and holds for trees of any depth (`:3-4`), so it does not matter that F can be deeper than T.
- **Q4 CONFIRMED** (`:61-74`). During an excursion T writes only z's until its final step, so a data index that is not in K still has its value from x_t. The kept reads therefore agree with F's walk. The state of T at a stage is determined by (mode, K), so reaching a dummy means T's state repeats inside an excursion, and the orbit could never return home. Data indices outside idx(F) are never read and stay constant. The x_t are distinct, so H is the exact period of the cycle of f_F.
- **Q5 CONFIRMED** (`:82-115`). Both step formulas are right. In Case II, a step from a = 1 to a = 1 must rewrite a, so every step is empty in T1°; the text omits this reason (finding 3). Case III: x is g0-periodic, and the exit happens at the unique empty state x_e. So the states with a = 1 have x = x* and number at most |C1|, and the states with a = 0 number at most |C0||C1|. In the corollary, T0° and T1° have the same index sets and depth ≤ r−1, so they are disjoint above level j−1. With j = r−4 and U_0 = D(4) = W_4, the shared node has depth ≤ r−5.
- **Q6 CONFIRMED** (`:121-135`). T0° keeps the read-once property and the shape, so L is unchanged. In the construction, T0° equals the Q(T0) labelling because its all-ones leaf was already empty. That leaf is used exactly once per round of C0, which gives q(p+1) states and the same orbit as solver-a Theorem 1 (`solver-a/proofs.txt:13-28`). T1's all-ones leaf is used exactly once. L ≤ W_r, with equality only for the complete tree. The equivalence with "reuse never helps" is a tautology, but it is accurate.
- **Q7 CONFIRMED** (`:139-150`). m − k = 2^r − 2^j − r + j = (2^r − 1 − r) + (j + 1 − 2^j), and j + 1 − 2^j ≤ 0 for j ≥ 1. Values: 3·2 = 6, 4·16 = 64, 5·2048 = 10240, 6·2^26 = 402,653,184 ≈ 4.03e8. The final inequality holds for r ≥ 1, with equality at r = 1.
- **Q8 CONFIRMED** (`:154-164`). (a) gives 01→00→10→01. T1° = T1 maps 0→1→1 and T0° sends everything to 0, so both have M = 1 and L = 6. (b): I replayed all 10 states and every one matches. Four states have bit 1 set. T1° on (b2, b4) runs 00→01→10→00, so M = 3. T0° has only fixed points. L(T0) = 4, L(T1) = 3, L = 15. The claims about r = 2 and about r = 3 with m = 3 match `out_brute_r2.txt:8` and `out_brute3_r3_m3.txt:40` (P2 count 0).
- **Q9 CONFIRMED with LOW wording defects.** The counts are in the output files: 5,478,539, 383,161 and 0 RD failures (`out_brute3_r3.txt:1,7`), 677 equalities and E ≤ 1 at depth 4 (`out_lazy2_r4.txt`), and 40,000 trees with 9,980 + 10,029 cycles that have ≥ 2 home states (`out_checkF.txt:1-2`). The false strengthenings (i)–(v) match P2 42, P3 1502, the empty-free path of 43, INJ 29958 and the shared-product count 112579. README:64-65 keep P1 and D(r) = W_r as conjectures. The top-level row (`README.md:47`) is accurate.
