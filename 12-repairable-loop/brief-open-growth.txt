THE PROBLEM
Read chain/3-question.txt (repairable loops; M(n) = least length of a loop that the mechanic can always make universal after one adversary edit).

WHAT IS ALREADY DONE (two independent solvers and a referee; you may read reports/solver-a.md, solver-b.md, referee.md, the proofs solver-a/proofs.txt and solver-b/proofs.txt, and use the programs in solver-a/, solver-b/, verifier/ read-only)
 - Computed: M(1) = M(2) = 4; M(n) = 2^n + 2 for n = 3, 4, 5; every shortest repairable loop for n <= 5 is universal.
 - Proved: 2^n + 2 <= M(n) <= 2^(n+1) for all n >= 3.
 - Computed three ways: no repairable loop of length 66 exists for n = 6, so 67 <= M(6); a repairable loop of length 76 exists, so M(6) <= 76.
 - Structure known: a repairable loop is a universal loop, or one plus an inserted cell, or one minus a cell (solver B Lemma 5). Universal loops of length 2^n + e are Eulerian circuits of the de Bruijn graph plus a balanced multiset of e extra edges. A universal loop that is repairable need only survive losses of isolated cells (length-1 runs); every other adversary edit can be undone exactly. For n >= 5 a universal repairable loop of length 2^n + 2 has only alternating words in its two surplus windows (solver B Theorem 3). The referee's run-count lemma: a repairable loop of length 66 (n = 6) has exactly 34 runs.
 - Open, and the headline of the problem: is M(n) - 2^n bounded? Both solvers guess not (sketches only: solver A P7, solver B Sketch 6). Both point at singletons in contexts such as 001011 (n >= 6) whose loss the cheap repair mechanisms cannot fix.

A clean way to think: after the loss of an isolated cell, some set of words of length n is uncovered; the mechanic's one edit creates at most n-1 new words; so every isolated cell must lie in a context where all but a repairable set of its words occur elsewhere in the loop.
