PROOFS (solver-b).  Each item is tagged COMPLETE or SKETCH.

Notation.  A loop v is a cyclic binary word; len(v) its length.  A window is a start index i; its word is
v_i..v_{i+n-1}.  mult_v(c) = number of windows with word c.  v universal <=> mult_v(c) >= 1 for all 2^n words c,
hence len(v) >= 2^n (there are len(v) windows).  A run is a maximal cyclic block of equal letters (loops with >= 2
runs).  S(v) = number of runs of length 1 ("singletons").  sigma = 2^(n-2).

FACT A (COMPLETE).  n >= 3, v universal of length l.  Then  sigma <= S(v) <= sigma + (l - 2^n).
Proof.  Cell i is a singleton run iff v_{i-1} != v_i != v_{i+1}, iff the window starting at i-1 has its word in
A = {c : c_0 != c_1 != c_2}; |A| = 2^(n-2).  So S(v) = sum_{c in A} mult_v(c).  All mult >= 1 gives S >= sigma.
sum over ALL c of (mult-1) = l - 2^n and every term is >= 0, so sum_{c in A}(mult-1) <= l - 2^n.   []

FACT B (COMPLETE).  Loop with >= 4 runs.  Doubling a cell of a run of length 1 changes S by -1, of a longer run
by 0.  Loss in a run of length >= 3: 0; of length 2: +1; of length 1 whose neighbour runs have lengths p,q (they
are distinct runs, they merge into one run of length p+q >= 2): -1 -[p=1] -[q=1].
So: no edit raises S by more than 1; a doubling never raises S; deleting a singleton that has a singleton
neighbour lowers S by at least 2.  (For a loop with 2 runs, "a doubling never raises S" still holds.)   []

FACT C (COMPLETE).  n >= 6, u universal, and w a loop from which u is obtained by one edit or by a pass.
Then w has >= 4 runs, a run of length exactly 2, and two adjacent runs of length 1.
Proof.  u contains 0110 and 1001 as factors, so it has a 1-run and a 0-run of length exactly 2; u contains 010101,
whose four middle cells are four consecutive runs R1..R4 of length 1.  w arises from u by the inverse of one edit:
remove one cell from a run of length >= 2, or insert one cell.  An inserted cell either equals a neighbour (one
run gets longer by 1) or differs from both neighbours (then it sits strictly inside a run of length >= 2, which
is split).  In every case at most ONE run of u is altered; every other run keeps its length, and two unaltered
runs adjacent in u stay adjacent in w (a cell inserted on the boundary between two runs lengthens one of them,
i.e. alters it).  So one of the two length-2 runs survives, and among R1..R4 at most one is altered, leaving
{R1,R2} or {R3,R4} as adjacent singletons.  These are 3 distinct runs, and the number of runs is even.   []

THEOREM 1 (COMPLETE for n >= 6; n = 3,4,5 are COMPUTED exhaustively, see report).
For n >= 6 there is no repairable loop of length L <= 2^n + 1.  Hence M(n) >= 2^n + 2 for all n >= 3.
Proof.  L <= 2^n - 1: after an adversary loss (or, if L = 1, a pass) the mechanic can reach length at most
2^n - 1 < 2^n.  Let L = 2^n + e, e in {0,1}, w repairable.  Adversary passes => w is within one edit of a
universal loop => Fact C applies to w.
 Move 1: adversary deletes a cell of a run of length 2.  S(w') = S(w)+1, len(w') = 2^n + e - 1.
   e=0: the mechanic must double; len(w'') = 2^n so S(w'') <= sigma (Fact A); S(w'') >= S(w') - 1 = S(w).
   e=1: loss is impossible (length).  Pass: w' universal of length 2^n, S(w') = sigma, S(w) = sigma - 1.
        Doubling: len(w'') = 2^n+1, S(w'') <= sigma+1, S(w'') >= S(w')-1 = S(w).
   In all cases S(w) <= sigma + e.
 Move 2: adversary deletes a singleton that has a singleton neighbour.  S(w') <= S(w) - 2, len(w') <= 2^n, so
   the mechanic passes or doubles, S(w'') <= S(w') <= S(w) - 2, and S(w'') >= sigma.  So S(w) >= sigma + 2.
 sigma + 2 <= sigma + e is false.   []

THEOREM 2 (COMPLETE).  M(n) <= 2^(n+1) for n >= 1.
Proof.  Let D be a de Bruijn cycle of order n and w = DD (length 2^(n+1) >= 2n).  Each word c occurs at two
windows i and i + 2^n, whose cell sets are disjoint because 2^n >= n.  A loss at cell k leaves intact (same
cells, still consecutive, same word) every window not containing k; a doubling at k leaves intact every window
not containing both k and k+1.  Two disjoint windows cannot both contain k, nor both contain {k,k+1}.  So after
any one edit at least one of the two windows of every word survives: w' is universal and the mechanic passes. []
(This bound is not sharp: M(1) = M(2) = 4, M(3) = 10, M(4) = 18, M(5) = 34.)

THEOREM 3 (COMPLETE).  n >= 5, w universal and repairable of length 2^n + 2.  Then the two surplus windows
(sum over c of (mult_w(c) - 1) = 2) carry the alternating words (01)^.. / (10)^.. only.
Proof.  For 1 <= j <= n-2 let A_j = {c : c_{j-1} != c_j != c_{j+1}}; as in Fact A, S(w) = sigma + (number of
surplus occurrences with word in A_j), for every j.  w contains 01010, so it has a singleton whose two
neighbours are singletons; the adversary deletes it: S drops by 3, the mechanic gains at most 1, and
S(w'') >= sigma, so S(w) >= sigma + 2.  Hence both surplus occurrences lie in A_j for every j = 1..n-2, i.e.
their words alternate at every position.   []
(Used to make the n = 6, L = 66, universal-w search exhaustive: uni128 with ALTONLY=1.)

LEMMA 4 (COMPLETE; the problem's lemma, confirmed).  If w is universal, the adversary's pass, any doubling, and
any loss in a run of length >= 2 are answered by pass / the inverse loss / the inverse doubling, returning w.
So a universal w is repairable iff every deletion of a length-1 run can be answered.  Deleting a length-1 run
cannot be undone (no edit splits a run).   []

LEMMA 5 (COMPLETE; justifies uni.cpp).  Every repairable w of length L is: a universal loop of length L, or a
universal loop of length L-1 plus one inserted cell, or a universal loop of length L+1 minus one cell.
Proof.  Adversary passes; the mechanic's pass / loss / doubling yields a universal loop.   []

SKETCH 6 (NOT a proof).  Why M(n) - 2^n should be unbounded (I expect >= c 2^n / poly(n)).
(a) Mechanisms that keep the surplus at 2 for n <= 5.  A deleted singleton s = b between runs a^p, a^q:
   - if p = 1 or q = 1 the mechanic shortens the merged run; the net effect is removing the pair "ab" from an
     alternating stretch, harmless if the alternating words are covered twice;
   - if p,q >= 2 ("isolated") and p >= n-1 (s touches a run of length >= n-1), the words that ended at s reappear
     across the junction ("sliding"), and one doubling in the alternating stretch that follows a^q rebuilds
     the rest (n = 5: 1^5 0 11 0 1 0 1 00 -> 1^7 0 1 0 1 00 -> 1^7 0 11 0 1 00).
(b) For n >= 6 the word 001011 forces a stretch of exactly two singletons between longer runs, and for n >= 7
   the word b aa b aa b (e.g. 1001001) forces isolated singletons with p = q = 2 between two b's.  Neither
   mechanism in (a) applies to them.  Heuristically, after deleting such an s the n words through s can only
   come back through the mechanic's own edit at a "twin" (a factor of w away from s equal to the context of s
   with one run changed by one cell); the edit destroys about n windows at the twin, which must then be covered
   twice.  The number of such contexts that must occur grows exponentially in n and one twin site can serve
   only O(n) of them; this suggests surplus >= c^n / poly(n) for some c > 1.  NOT PROVED.
(c) What is missing: the step "the destroyed twin windows must have multiplicity >= 2 in w" needs the context
   of s beyond one window (2n-1 cells), which universality does not control; periodic contexts (period n or
   n-1, as in cycle-joined de Bruijn sequences) allow coincidences that I could not exclude in general.
   So (b) is a heuristic, and "M(n) >= (1+d) 2^n" is neither proved nor supported by data.
