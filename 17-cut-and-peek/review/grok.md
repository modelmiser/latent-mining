Q2: CONFIRMED — (*) and row(1,1,1) = (z^{s₁}+z^{s₂}+z^{s₃}−2)W follow by substituting 2a_i = (1−z^{s_i})W (`README.md:86-91`). For S ≠ 0, two unit complex numbers with sum S have product S/conj(S), so they are one unordered pair; that forces case (N). Both sums vanish only for even m, since −1 must be an m-th root (`solver-b/proofs.txt:51`); if either θ is 0 this is again r s_ik = θ_i+θ_k, and otherwise r(s_ik−s_i−s_k) ≡ −2θ_k because m/2 ≡ −m/2. Any two pairs share a vertex, so the written (1,2),(1,3) exclusion (`README.md:107-108`) is every choice up to relabeling. With no exceptional pair every pair has a zero θ, so at most one θ is nonzero and r t = θ₁+θ₂+θ₃. With exceptional pair (k,l), the other pairs are non-exceptional and θ_k, θ_l ≠ 0, so θ_i = 0 and ω^{rt} = −1 (`README.md:113-115`). Vanishing frequencies match as 0 = 0, so the transforms agree and row(1,1,1) = z^t W. A period makes s_i non-unique but ω^{r s_i} is unique wherever the transform of W is nonzero, so every admissible choice gives the same z^t W. — none
