PROOFS (solver-b).  Each item is tagged COMPLETE or SKETCH.

Notation. A protocol is (Q,qA,qB,w,d). "Legal", "R", "good", "wins" as in the problem text.
n = a+b+1 is the number of agents of instance (a,b,x).

------------------------------------------------------------------------------------------
L1 (reduction to one outcome per unordered pair, no swaps).  COMPLETE.
Given d, define d' by: for p<q, if d(p,q) is neither (p,q) nor (q,p) put d'(p,q)=d(p,q), d'(q,p)=(q,p);
else if d(q,p) is neither (q,p) nor (p,q) put d'(q,p)=d(q,p), d'(p,q)=(p,q); else both identity.
d'(p,p)=d(p,p).  Claim: d' wins every instance that d wins.
Proof. Every d'-legal move is a d-legal move, so R' is a subset of R and every edge of R' is an edge of R.
Hence a configuration on a cycle of R' is on a cycle of R, so it is good.  Let c in R' have no d'-legal move.
If c has no d-legal move it is good.  Otherwise some pair (p,q) of states present in c is d-legal but
neither order is d'-legal; then p != q (d' = d on equal pairs) and by construction d(p,q), d(q,p) are each
identity or swap, and one of them is a swap; a swap is a legal move that leaves the multiset unchanged, a
self-loop of R at c, so c is good.  QED.
Consequence: G(s) can be computed over maps f: unordered pairs -> unordered pairs ("reduced model").
The search program has both the reduced model (mode 0) and the literal ordered model (mode 1).

L2 (G is non-decreasing).  COMPLETE.
Add a state q' with w(q')=w(qA), d(q',y) = d(qA,y) and d(y,q') = d(y,qA) when those are not the identity on
(qA,y) resp. (y,qA), identity otherwise (and d(q',q') from d(qA,qA) likewise).  The map "rename q' to qA"
sends configurations of the new protocol to configurations of the old one, legal moves to legal moves
(possibly to self-loops), terminal configurations to terminal ones, cycles to closed walks, and preserves
goodness.  So the new protocol wins (a,b,x) whenever the old one wins (a,b,x) (x=q' maps to x=qA).  QED.

T1 (MAIN: G is superlinear; conservative weight protocol C(W)).  COMPLETE.
Let W be a finite set of positive integers, K = max W, with
  (C) for all x>y in W:  x-y is in W, or x-y = z1+z2 with z1,z2 in W;
  (S) call w in W splittable if w = x1+x2 with x1,x2 in W; let U = the largest non-splittable element.
Protocol C(W): states P_w (output A) and N_w (output B) for w in W, and wa (output A), wb (output B);
qA = P_K, qB = N_K; s = 2|W|+2.  "Weight" of P_w is +w, of N_w is -w, of wa, wb is 0.  Rules (same
outcome for both orders of a pair; everything not listed is the identity):
  cancel:  {P_x,N_y}, z=x-y.  z=0 -> {wa,wb}.  z>0 -> {P_z,wa} if z in W, else {P_z1,P_z2}.  z<0 -> mirror
           image with N and wb.
  split:   {P_x,wb} with x splittable -> {P_x1,P_x2};   {N_x,wa} with x splittable -> {N_x1,N_x2}.
Claim: C(W) wins every instance with (a+b)*U + 1 <= K.
Proof. (i) Every rule preserves the sum Sigma of weights.  (ii) Every legal move strictly decreases
(sum of |weights|, number of agents in {wa,wb}) lexicographically: a cancel lowers the first component
from x+y to |x-y|; a split keeps the first and lowers the second by one.  So R has no cycle and no
self-loop, and it suffices to show every terminal configuration T in R is good.  (iii) Let a-b >= 2.
Initially Sigma = K(a-b) + weight(x) >= 2K - K = K > 0.  So T contains some P.  T contains no N, since
any {P_x,N_y} is legal.  So the agents with nonzero weight are all P's and their weights sum to
Sigma >= K.  Suppose T contains a wb.  Then T has at most n-1 = a+b agents of type P.  If all of them
were non-splittable, Sigma <= (a+b)U < K, a contradiction; so some P_x in T is splittable and {P_x,wb}
is legal, contradicting terminality.  So T consists of P's and wa's: good.  The case b-a >= 2 is the
mirror image.  QED.
Corollary A.  W_m = {1,...,m-1} u {m,2m,...,m*m} (m>=2) satisfies (C) (every z in [1,m^2] is a*m+c with
0<=c<m, a sum of at most two elements) and (S) with U=1 (c = (c-1)+1, m = (m-1)+1, a*m = (a-1)*m + m).
|W_m| = 2m-1, so s = 4m and  G(4m) >= m^2 - 1.  With L2:  G(s) >= floor(s/4)^2 - 1  for all s >= 8.
Corollary B (HEADLINE).  No constant C has G(s) <= C*s for all s: take m > 4C+1, s = 4m; then
G(s) >= m^2-1 > C*4m.
Corollary C.  For any W with (C) and U=1:  G(2|W|+2) >= max W - 1.  Sets found by exhaustive search
(wsearch.cpp; conditions re-checked by gen_cons.py, which refuses a W violating (C)):
  |W|=3 {1,2,4}; 4 {1,2,3,6}; 5 {1,2,4,5,10}; 6 {1,2,4,6,7,14}; 7 {1,2,3,6,8,9,18}; 8 {1,2,3,6,9,11,12,24};
  9 {1,2,4,5,10,12,15,16,32}; 10 {1,2,3,4,7,11,15,17,18,36}.
Remark (limit of this construction, SKETCH): (C) forces W u (W+W) to contain many integers below K, so
|W| is at least of order sqrt(K); this family cannot give more than G(s) = Omega(s^2).

T2 (the "budget" protocol of the problem text; G(s) >= floor((s-6)/2)).  COMPLETE.
Budget protocol with parameter K wins every instance with a+b <= K-2.
Proof. Every legal move strictly lowers the sum of |weights| (cancel by >= 2, flip by 1), so no cycles or
self-loops.  Let a-b >= 2, Sigma = signed weight sum; initially Sigma >= 2K-K = K.  A cancel keeps Sigma;
an "A-flip" (positive meets wb) lowers Sigma by 1 and turns one wb into wa; a "B-flip" raises Sigma by 1.
An agent that is weak stays weak, and a weak agent turns from wa into wb only as the flipped party of a
B-flip.  So (#A-flips) <= (#wb ever created) <= [x=wb] + (#agents that pass from a nonzero weight to wb)
+ (#B-flips) <= n + (#B-flips).  Hence at a terminal configuration Sigma >= K - n = K-(a+b)-1 >= 1, so a
positive agent is present; terminality then excludes negative agents and wb.  Good.  Mirror for B.  QED.
(Computed: the budget protocol actually wins exactly up to N=K+2 for K=1,3,5 and N=K+1 for K=2,4.)

T3 (necessary structure when a protocol wins ALL instances; partial).  COMPLETE as stated, but it does
NOT decide whether G(s) can be infinite.
If a protocol wins every instance (G = infinity) then every play from every sub-multiset of every initial
configuration is finite.
Proof. Let P be a sub-multiset of an initial configuration with an infinite play.  Some configuration c of
P recurs, so it lies on a cycle.  P embeds in an A-majority instance I_A and in a B-majority instance I_B
such that at least one qA and one qB are outside P in both (add copies of qA, qB).  The scheduler may play
only inside P; then c + (idle rest) lies on a cycle of R(I_A), so the idle qA and qB both have output A;
the same in I_B gives output B.  Contradiction.  QED.
Finite version (same proof): if a protocol wins all instances up to N, plays inside sub-populations of
size <= about N/2 are finite.
